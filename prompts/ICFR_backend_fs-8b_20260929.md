### 0.3 구조 추론 알고리즘 — 프로토타입 실측
스크래치패드 프로토타입(저장소 밖)으로 실 샘플에 돌린 결과:

| 시트 | 행 | 기간 | 소계 오류 | 비고 |
|---|---|---|---|---|
| BS공시 | 40 | 2025·2024 | **0 / 0** | 자산총계·부채총계·자본총계·부채및자본총계 트리 복원 |
| PL공시 | 19 | 2025·2024 | **0 / 0** | 사다리 → 트리(영업이익 ⊃ 영업수익(+)·영업비용(−) …), 비용 −1 자동 |
| CF공시 | 60 | 2025·2024 | **0 / 0** | `(3) 수익차감`·유출액 −1, `V.` = I+II+III+IV, `VII.` = V+VI |
| BS정산표 | 97 | 2020~2025 | 각 2 | 전부 `지배주주지분` 원본 수식 누락(0.2) — 파서가 정확히 잡음 |
| PL정산표 | 62 | 2023~2025 | **0 / 0 / 0** | 2022 중복 열 → 해당 연도 제외 + 경고 |

알고리즘 요지 (구현 시 그대로 옮긴다):
1. **수준 힌트**: 접두 순위(로마 1 < 아라비아 2 < 괄호 3 < 가나다 4) × 10 + 들여쓰기(indent×2 + 앞 공백 수). 접두 없고 들여쓴 행 = 잎(100+). **접두·들여쓰기 모두 없는 행(flat)은 금액으로 판정.**
2. **머리 소계(header)**: 다음 행이 더 깊으면 머리. 자식 부호는 풀이로 구한다.
3. **합계 행(footer)**: 앞선 형제(또는 최상위 노드)의 **끝 구간**을 부호 조합으로 맞춰 보고, 맞으면 그 구간을 자식으로 삼는다(가장 짧은 구간 우선). PL 사다리·BS 총계·CF 기말현금이 전부 이것으로 풀린다.
4. **부호 풀이는 모든 기간을 동시에 만족해야 채택**한다. 한 기간만 보면 `상환할증금 0 = 0 + 0` 같은 우연 일치가 생긴다(실측). 0 이 아닌 값이 하나도 없으면 근거 없음으로 본다. 음수 개수 최소 해를 고르고, 해가 여럿이면 `sign_ambiguous` 표시. 자식 12개 초과면 1~2개 뒤집기까지만 탐색.
5. **BS 섹션**: 금액 없는 `자산`/`부채`/`자본` 행을 섹션 머리로 본다(제안값, 사람이 확인). 부채·자본을 함께 묶는 합계는 `liability_equity`.
6. **PL 섹션**: 합계 행·부호 섞인 소계 = `profit`, 나머지는 루트까지 부호 곱이 +면 `revenue`, −면 `expense`. **CF 섹션**: 최상위 머리 이름의 `영업활동`/`투자활동`/`재무활동`, 나머지 `cf_other`.
7. **이름을 쓰는 곳은 제안값뿐이다**(섹션 머리·CF 섹션·주당이익 제외). 검증(8-A)은 여전히 이름을 보지 않는다.

### 파서 규칙 (ADR §3 + 실측)
- 금액: 괄호·`△`→음수, `-`→0, 빈칸→None(0 아님), bool(검산 열) 무시, 부동소수 잡음(|x−round(x)|<1e-6)은 정수+`float_noise` 기록, **소수는 행 오류로 거부**(반올림 금지).
- 단위: 머리 영역 `단위 : 원|천원|백만원` 감지. 못 찾으면 `unit` 필수(없으면 422). 감지값과 `unit`이 다르면 422. `억원` 등 미지원 단위 422. **추정 금지.**
- 데이터 끝: 라벨이 문자열이 아닌 행 또는 `[…]` 라벨에서 멈춘다. 라벨 없는 행은 건너뛰되 선택 열에 숫자가 있으면 경고.
- 원본 보존: `raw_row_no`·`raw_label`(원문 그대로)·`raw_indent`·`raw_value`(셀 원문)·`raw_meta`(주석번호, 안쪽/바깥 열, 조정 열 값 `{조정전, IFRS조정, 감사수정}`, 매핑 열, 추론 플래그). 헤더 `source_kind`·`source_filename`·`source_sheet`.
