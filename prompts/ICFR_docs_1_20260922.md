## 2. §10 교체 내용
절 제목은 "실행 절차 (무인)"으로 바꾸고, 아래 내용을 기존 문서 문체에 맞춰 작성한다.

- **새 작업 전 세션 종료**: 이전 작업 세션은 `/exit`로 닫고 시작한다.
- **필요 모델 표기**: 모든 프롬프트 파일은 맨 위에 "필요 모델"을 적는다.
- **STEP 0 (Opus 1차 실행)**
  - 실행: `claude --model opus --dangerously-skip-permissions "<파일>.md 진행해줘"`
  - 조사·실측·설계안을 보고하고 **멈춘다**. 이 단계에서는 코드·DB·설정을 수정하지 않는다.
- **구현 (Sonnet 이어서 실행)**
  - 실행: `claude --continue --model sonnet --dangerously-skip-permissions`
  - 마스터가 STEP 0 보고에 대한 확인 답을 붙여넣으면 그것에 따라 구현한다.
- **Opus 유지 예외**: 기존 데이터를 변경하는 마이그레이션, 권한·보안, 금액 계산 작업은 구현까지 Opus로 진행한다. 이 경우 `--continue`에서도 `--model opus`를 사용한다.
- **서버 명령은 마스터가 직접 실행**: 운영 서버·운영 DB 명령(백업, psql, docker, 배포 확인, 시드 실행)을 Claude Code가 실행하지 않는다. 필요한 명령은 복사할 수 있는 코드 블록으로 제시하고, 마스터가 결과를 붙여넣을 때까지 기다린다.
- **마이그레이션 포함 작업 순서**: 마스터 백업 → push(PowerShell) → 배포 확인 → 필요 시 시드. 각 단계의 명령은 위 원칙에 따라 코드 블록으로 제시한다.
- **문서만 변경하는 작업**은 STEP 0 없이 단일 실행한다.
